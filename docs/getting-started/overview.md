# Getting Started with Docify

Welcome to Docify! This guide will walk you through the fundamental concepts and help you get up and running quickly.

## What is Docify?

Docify is an internal documentation platform that syncs content directly from GitHub repositories. It combines the power of Git with a beautiful, searchable documentation interface.

### Key Features

- **Git-Powered** - Your docs live in Git, sync automatically to Docify
- **Full-Text Search** - Search across all your documentation instantly
- **Team Collaboration** - Built-in permissions and role-based access
- **Beautiful UI** - Clean, intuitive interface powered by Chakra UI
- **Markdown & MDX** - Write docs in your favorite format

## Before You Start

Make sure you have:

- [ ] Access to a GitHub repository with documentation
- [ ] A Docify account (or admin access to create one)
- [ ] Basic familiarity with Markdown

## Your First Steps

1. **Connect Your Repository** - Link your GitHub repo to Docify
2. **Configure Your Space** - Set up the documentation path and settings
3. **Review Your Content** - Verify the docs synced correctly
4. **Share with Your Team** - Invite team members and set permissions
